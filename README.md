# 🍅 Pomodoro Pro — продуктивность без суеты  
Современный Pomodoro-таймер с задачами, статистикой, тёмной/светлой темой, конфетти и локальным хранилищем.  
Проект разработан **Андреем Викуловым (VProger)** как демонстрация навыков JS, TailwindCSS и работы с состояниями в браузере.

---

## 🚀 Возможности
- ⏱ Помодоро-таймер (Work / Break / Long Break)
- 🔁 Автоматическое переключение фаз
- 🧠 Список задач с прогрессом
- 📊 График продуктивности за день/неделю (Chart.js)
- 💾 LocalStorage: задачи, настройки, статистика
- 🌓 Светлая/тёмная темы
- 🎉 Конфетти при завершении цикла
- 🎧 Звуковой сигнал
- 📱 Полностью адаптивный интерфейс
- ⚡ Без зависимостей — всё на чистом JS

---

## 📂 Структура проекта
```

pomodoro-pro/
│ index.html
│ style.css          # Tailwind build (или CDN)
│ main.js            # Инициализация и маршрутизация
│ timer.js           # Логика таймера
│ tasks.js           # Задачи + LocalStorage
│ stats.js           # Статистика (Chart.js)
│ theme.js           # Переключение темы
│ storage.js         # Безопасные операции с LocalStorage
│ confetti.js        # Эффект при завершении
│ README.md
└── assets/
ding.mp3
icon.png
logo.svg
```
